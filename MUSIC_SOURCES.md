# Classical music sources

The Bach and Beethoven compositions are public domain. `audio/midi/` holds the rebuilt classic recordings. `audio/Midi_beautiful/` holds the rebuilt piano recordings behind the Midi New music option; they are still being refined, and their file names carry a version suffix (for example `BABY_v7_loop.ogg`). Individual score declarations are recorded above; all seven selected records have `license_conflict=False`. These are archived source declarations, not an independent verification of every uploader's rights. See the [PDMX license-conflict notice](https://github.com/pnlong/PDMX#updates-).

[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) is a dedication of rights held by the affirmer. [Public Domain Mark 1.0](https://creativecommons.org/publicdomain/mark/1.0/) identifies an existing public-domain status; it is not a copyright waiver. These source terms are distinct from the license for new project-authored performances.

The BWV 902 digital source is labeled “902a” because it includes an alternate prelude. The rebuilt track uses only the second movement, the historical BWV 902 Fughetta. The BWV 814 track uses the Menuet without the Trio.
